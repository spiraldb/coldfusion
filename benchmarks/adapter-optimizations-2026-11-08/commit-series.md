# Retained implementation series

Native means `spiraldb/iceberg-rust`; public means `spiraldb/coldfusion`; private means the benchmark integration in `spiraldb/spiraldb`.

All 12 commits below are marked CLEAR in the designated review record. The native extension contains four changes on top of the original nine retained patches; the final exported native series has 13 patches. The series combines reader optimizations with new integration capabilities, correctness, reproducibility and benchmark-harness work.

Mean-based evidence: Exact pushdown improved derived rate by 2.8% for Zstd and 3.8% for LZ4_RAW in paired full 22-query SF10 runs. Layout batching improved the five-query screen by 1.42x; that is not a full-suite claim. The native-source bundle improved paired full 22-query rate by 1.182x. Revision alignment, file caching, API plumbing, packaging and optimizer guards were not timed independently. Views remain optional and were not selected as a global default.
